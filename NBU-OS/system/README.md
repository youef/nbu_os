# NBU-OS system files

This directory contains the private operating-system layers. It is source code and configuration for NBU-OS, not a Linux distribution.

- `system/boot`: boot contract and platform startup notes.
- `system/kernel`: kernel subsystem contracts.
- `system/security`: credential and security policy.
- `system/exec`: private NBU-EXEC-1 contract.
- `programs`: applications owned by NBU-OS.
